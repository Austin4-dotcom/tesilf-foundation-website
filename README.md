# TESILF Foundation Website

React + Vite responsive foundation website starter populated with the verified organisational information supplied by TESILF.

## Run
1. Install Node.js 20+.
2. In this folder run `npm install`.
3. Run `npm run dev`.
4. Open the local URL shown by Vite.

## Important
The site intentionally does not invent beneficiary totals, partner logos, audited figures, awards, testimonials, payment instructions, or programme outcomes. Replace the photography and add verified evidence/documents as they become available.
